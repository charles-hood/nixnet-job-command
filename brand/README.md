# nixfred brand files

These SVGs are the official nixfred brand marks, copied unmodified from
the [nixfredOS brand standard](https://github.com/nixfred/nixfredOS/blob/main/brand/README.md).

Do not recolor, stretch, restyle, or redraw them.

| File | Use |
|---|---|
| `nixfred-favicon.svg` | Browser tab icon (icon on a `#070707` tile). Also used as `app/static/favicon.svg`. |
| `nixfred-icon.svg` | Icon only, dark backgrounds. Also used as `app/static/logo.svg`. |
| `nixfred-icon-light.svg` | Icon only, light backgrounds. |
| `nixfred-logo.svg` | Full lockup, dark backgrounds. |
| `nixfred-logo-light.svg` | Full lockup, light backgrounds. |
| `favicon-32.png` | 32 px PNG fallback for older browsers. |

The Larry face appears only as the dot on the i in the wordmark. The
hexagon always shows the `>_` prompt, never the face.
